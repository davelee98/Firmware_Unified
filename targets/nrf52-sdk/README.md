# Target: nRF52 legacy (Nordic SDK, bare C)

Source repo: `Firmware_NRF` (https://github.com/OpenDisplay/Firmware_NRF)

**Out of scope — treat as end-of-life.** Not imported, and migration is not planned. This is
the older bare-C Nordic SDK target; the Nordic parts that are being carried forward
(nRF54L15, nRF52840) live on Zephyr in `targets/nordic-zephyr/`.

Confirm this target is genuinely no longer shipped, then delete this directory and drop it
from the docs. Until someone confirms that, it stays here as a marker rather than a plan.
Owned by the OpenDisplay org rather than a personal fork.
